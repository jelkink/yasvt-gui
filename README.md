# yasvt-gui

Yet Another Simple Vocabulary Trainer: a GTK 4 graphical vocabulary trainer written in C. It is a port of [yasvt-python](https://github.com/) with the same scoring and test ideas.

## Features

- Load one or more CSV vocabulary files and practise them in random order.
- Four test modes, each switchable on or off in the side panel:
  - **Translate**: see the source word, type the translation.
  - **Type the word**: see the target word, type it out.
  - **Hear and translate**: hear the source word, type the translation.
  - **Hear and type**: hear the target word, type it out.
- Spoken words (English, Russian, Chinese, Cantonese, Italian) via Google TTS, cached locally.
- Pinyin shown automatically for Chinese words.
- Per-word score history: well-known words come back less often.
- Reverse the list direction, shuffle, print the list with scores, clear a word's score, or delete a word.

## Requirements

- A C compiler, `make`, `pkg-config`
- GTK 4 development files
- `curl` and `mpv` (only for audio)

## Build and install

```bash
make                           # build into build/yasvt-gui
make run                       # build and run
sudo make install              # install to /usr/local, with a desktop entry
make install PREFIX=$HOME/.local   # per-user install, no sudo
make uninstall                 # remove (use the same PREFIX)
```

## Usage

```bash
yasvt-gui [--start N] [--number N] [--new PCT] [FILE...]
```

- `--start N`, `-s N`: first word to use, counted from 1 (default 1)
- `--number N`, `-n N`: number of words to use (default: all)
- `--new PCT`, `-N PCT`: share of never-seen words in the initial order, 0 to 100 (default 20)

Files can also be opened from the **Open…** button. Opening files replaces the current word list. Started without files, the program continues with all words you have practised before, taken from the progress file (`~/.local/share/yasvt-gui/progress.txt`).

## Vocabulary files

CSV with a header row naming the two languages, then one word per row. An optional third column holds a note shown after a wrong answer.

```csv
Russian,English
возможно,maybe
вероятно,probably
```

Language names (case-insensitive) decide whether audio and pinyin are available. See [examples/](examples/).

## Audio

Clips are downloaded from Google Translate TTS with `curl` and played with `mpv`. They are cached in `~/.cache/yasvt-gui/`, so each word is only downloaded once. Audio needs an internet connection the first time a word is played.

## Development

`src/pinyin_table.c` is generated by `tools/gen_pinyin.py`, which needs the `pypinyin` Python package:

```bash
python3 tools/gen_pinyin.py > src/pinyin_table.c
```
